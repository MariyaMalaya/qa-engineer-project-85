 Codebattle ( https://codebattle.hexlet.io/) — проект Хекслета.Игра Версии которой разрабатываются целиком и полностью силами комьюнити. Суть заключается в том, 
что два программиста одновременно выполняют одну задачу, на разных языках программирования. Кто выполнил быстрее, тот побеждает.


about.yml - Возможности проекта
requirements.yml -описание требований проекта.
test-cases.yml - тест-кейсы для проведения тестирования
testing-report.yml - результат прохождения тест-кейсов с отметкой (pass/fails)
issues.yml -описание дефектов и шагов по их воспроизведению
reopened_issues.yml - отчет о проведенном регрессионном тестировании и новые баг-репорты
